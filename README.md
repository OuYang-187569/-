# 第 21 届智能车竞赛卡丁车省赛硬件

本仓库开源第 21 届智能车竞赛卡丁车省赛所使用的硬件设计，工程文件使用立创 EDA 专业版格式。

## 工程文件

| 文件 | 说明 |
| --- | --- |
| `ProPrj_21届智能车第七版_2026-07-27.epro2` | 主控/整车相关硬件工程（第七版） |
| `卡丁驱动.epro2` | 卡丁车驱动板硬件工程 |

## 使用方法

1. 安装并打开[立创 EDA 专业版](https://pro.lceda.cn/)。
2. 在编辑器中选择“文件 → 导入 → 立创 EDA（专业版）”。
3. 选择对应的 `.epro2` 工程文件并完成导入。
4. 打板或装配前，请自行复核原理图、PCB、器件封装、BOM 和制造参数。
